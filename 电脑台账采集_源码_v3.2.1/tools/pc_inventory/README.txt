电脑资产离线采集初版（0.1.0）

适用范围
适用于具备 Windows PowerShell 5.1 和本机 CIM 服务的 Windows 电脑。
不适用于国产 Linux、macOS、打印机、交换机、摄像头等设备。
这是初版，已完成静态语法检查，尚未在各站真实电脑验证。
已提供模拟测试用例；开发机执行策略禁止脚本运行，未绕过策略，因此尚未执行模拟测试。

怎么运行
1. 将本文件和 Collect-PCInventory.ps1 放在单位允许使用的本地文件夹。
2. 在该文件夹打开 Windows PowerShell，输入：
   powershell.exe -NoProfile -File .\Collect-PCInventory.ps1
3. 按提示输入设备编号、使用人员、所在位置等；不确定时直接回车留空。
4. 脚本所在文件夹的“结果”子文件夹会生成一份 CSV 和一份 JSON。
   每次文件名包含时间和随机字符，不覆盖之前的结果。

跳过提问、只采自动信息：
   powershell.exe -NoProfile -File .\Collect-PCInventory.ps1 -NonInteractive

指定本地保存文件夹并填写部分人工字段：
   powershell.exe -NoProfile -File .\Collect-PCInventory.ps1 -NonInteractive -OutputDirectory "C:\台账采集结果" -DeviceNumber "PC-001" -DeviceType "台式机" -Location "某站办公室"

还可使用的参数：
   -Sequence 序号；-AssignedTo 使用人员；-DeviceStatus 状态；
   -AcquiredDate 取得日期；-Remarks 备注。
参数值有空格时请加双引号。

权限和保密
普通账户运行即可；某些单位设备可能限制 CIM 读取，失败会标注“待核实”。
如果单位执行策略禁止运行脚本，请交信息化管理人员按制度处理，不要绕过策略。
脚本不要求管理员权限，不修改系统配置，不调用网络接口，不扫描其他电脑。
只读取本机 CIM 的硬件、操作系统、物理磁盘、网卡及当前地址。
不会读取个人文件、密码、密钥、浏览记录或软件清单，也不把登录账户作为使用人。
不会连接云端；输出限制为普通本地目录，拒绝 UNC、映射网络盘和目录联接。
请选未启用云同步的本地文件夹；脚本不能判定所有第三方同步软件。
结果含设备序列号、IP、MAC 和手工填写的人员信息，请按单位规定保管和流转。
跨电脑采集需使用单位允许的介质；使用 U 盘前遵守单位介质管理和查毒规定。
程序没有自动脱敏或加密功能，请勿把真实结果发到外部平台或公开位置。

自动采什么、还要核对什么
自动：品牌型号、物理磁盘序列号、网卡 MAC 和 IP，以及 CPU、内存、系统、BIOS 整机序列号。
多块硬盘逐一列出，多张网卡用同一网卡编号配对 IP/MAC，不会把不同网卡地址混配。
数量记为 1，代表当前这台电脑；设备类型、编号、人员、状态、日期、位置由人工填。
取得日期应查采购/固定资产资料，不能用系统安装日期替代。
设备编号应使用本单位资产口径，不能用计算机名称或整机序列号自动代替。
物理磁盘序列号不是 C 盘等分区的卷序列号，不使用卷号替代物理盘号。
明显 USB/可移动存储及虚拟、VPN、隧道、蓝牙等适配器会被过滤，并给出说明。
非 USB 外置盘可能无法区分，请现场确认；特殊用途适配器可在人工台账补录。
断网不代表没网卡；读不到不代表设备不存在或没有序列号。
品牌型号、固件填写的整机序列号及磁盘序列号仍须核对铭牌/资产记录。
IP 是采集时地址，会因 DHCP、网络连接变化；不同站点要在实际使用网络下核对。
内存以 GiB 显示；磁盘容量等完整结构保存在 JSON 中。
打印机、显示器、UPS、交换机、摄像头、门禁、服务器等须另外盘点，不能只收电脑。

怎么进 Excel
CSV 是采集结果，不等同于参考 Excel 的格式和完整台账，也不会改写原始模板。
中文使用带 BOM 的 UTF-8。建议用 Excel“数据—从文本/CSV”导入。
设备编号、物理盘序列号、MAC、取得日期等列应设为文本，避免丢失前导零或变成科学计数。
CSV 对可能触发 Excel 公式的单元格加了前置单引号；JSON 保留原始值。
核对后把需要的字段填入正式台账，保留 JSON 便于后续本地汇总或核查。
多机结果可汇集到单位允许的本地目录；本初版暂不包含自动汇总器或软件清单。

模拟测试（不采集运行电脑信息）
   powershell.exe -NoProfile -File .\Test-PCInventory.ps1
测试通过构造模拟 CIM 对象验证多盘、多网卡配对、缺失信息和导出；不执行真实采集。
测试产物含“TEST_ONLY”标记，保存在 test-output 下，不能当作资产记录使用。
